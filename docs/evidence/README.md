# Evidence records

Pinned measurement and observation records that documentation links to as raw
data for engine claims (accessibility, GPU UI, pointer performance, clipboard).
They were produced with the former TSX Showcase example, removed on 2026-11-06;
source paths and digests inside them refer to that example at the recorded
commit and can be inspected through git history. The records are historical:
they are not regenerated and do not prove the current tree.
